# Sillage

Thème sombre pour Orbit, composé d’un fond charbon légèrement chaud, de surfaces mates et d’un accent corail terreux. Les jeux restent présentés en tuiles 16:9, réparties par statut. Les films et séries conservent leurs affiches verticales.

## Activation

Dans Orbit : **Réglages → Apparence → Sillage**. Le choix est enregistré comme les autres thèmes.

## Désactivation

Choisir un autre thème dans Apparence. Pour retirer Sillage du projet, enlever son import et son entrée dans `themes/index.js`, puis supprimer ce dossier.
